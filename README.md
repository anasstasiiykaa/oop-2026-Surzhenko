# AutoServiceApp

- **Варіант:** 3

## Проєкт
**AutoServiceApp** – консольний застосунок для первинного обліку автомобілів та їх власників у автосервісі.

## Технології
- C#
- .NET 10
- Visual Studio Code
- Git / GitHub

## Функціональність
- Облік автомобілів і власників.
- Обчислення вартості обслуговування автомобілів і мотоциклів через інтерфейс `IServiceable`.
- Сервісні замовлення з переліком операцій і розрахунком загальної вартості.
- Валідація некоректних даних та обробка винятків (`ArgumentOutOfRangeException`, `ArgumentException`).
